# Structural Risk, mapped

An explainer field map for the Structural lane of the [AI Safety Front Door](https://idvorkin-ai-tools.github.io/safety.html): what AI does to the world around it even when no one misuses it and nothing malfunctions.

Live: https://idvorkin-ai-tools.github.io/structural-risk-field-map/

Twelve pages in three arcs: the problem (structural risk, gradual disempowerment, replies), power and races, and the levers (compute governance, export controls, compute thresholds, safety frameworks and the EU code, liability, international coordination). Each page lists only sources that were fetched and read.

Static HTML. `paper.css` is shared by every part; `nav.js` turns each part's eyebrow into a page selector. Plain / Technical / ELI5 modes and term boxes come from the org hub's `assets/terms.js` and `assets/glossary/` (see `docs/SHARED-TERMS.md` in `idvorkin-ai-tools.github.io`).
